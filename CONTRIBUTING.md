# Contributing

Thanks for wanting to help Queer Global.

1. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
2. Check [STATUS.md](STATUS.md) so you are not working on a page that is only a stub by accident.
3. Prefer issues and pull requests on [qg-frontend-v2](https://github.com/QueerGlobal/qg-frontend-v2) for app work, and on this repo for docs.

## Pull requests

- Branch from `main`. Do not push to `main`.
- Keep the change focused.
- In the PR, say what you changed and how you checked it.

There is no staging deploy from this documentation repo. There is no public website yet.
