# Development

The product people should run locally is the intended web app, not this docs repo.

## qg-frontend-v2

```bash
git clone https://github.com/QueerGlobal/qg-frontend-v2.git
cd qg-frontend-v2
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). See that repo's README and [STATUS.md](STATUS.md) for what actually works.

## This repository

Edit Markdown, open a pull request. No app server, database, or third-party keys are required.
